## Full description

Marion Wx Map is a free, on-device weather and aviation map centered on Marion, Virginia.

See radar, storm tracks, lightning, and nearby ADS-B aircraft on one map. Recenter with a ZIP code and clean up trails when the display gets cluttered.

**What’s free**
- The app is free to download and use. No subscription. No Google Play Billing.
- Optional tip via Cash App ($AnthonyDean16) if you want to support development. Tips are optional support — not required to use any feature.

**Features**
- Weather radar layers
- Storm tracking
- Lightning overlay
- ADS-B aircraft positions
- ZIP code recenter
- Trail cleanup

**About the data**
This is not a commercial weather service. The app uses public free feeds and runs on your device. Map data is fetched from third-party public sources over the network from your phone — there is no Ardean backend collecting personal data for the map itself.

Source / project: https://github.com/ardean1/marion-wx-map

Use common sense for weather decisions. Official warnings come from the National Weather Service and local authorities.
